# Accreditation and Exemplar Memo

Date: 2026-07-25

## Summary
The course must be defensible under ABET and CS2023-style expectations. That means professional dispositions, communication, teamwork, design, evaluation, and a comprehensive project experience.

## End-to-end summary
This memo sets the accreditation target for the whole redesign. A course that wants to look like a legitimate degree-level offering has to show more than technical content: it must demonstrate professional dispositions, communication, teamwork, design ability, evaluation, and a comprehensive project experience. The exemplars then show that this is not hypothetical. CMU, Stanford, and Berkeley-style patterns already exist that combine real work with assessment structures suitable for serious computing education.

## What matters most
- ABET student outcomes for design, communication, teamwork, and professional responsibility
- A comprehensive project that applies prior technical knowledge and professional dispositions
- CS2023 competency and disposition framing
- A capstone-style project spine
- Oral defense as the main verification method

## Exemplar patterns worth stealing
- CMU ML in Production / AI Engineering
- Stanford CS336 style policy distinction around AI use
- Berkeley advanced LLM agent course with tiered deliverables

## Main gaps
- The current package has knowledge coverage but weak disposition coverage
- No comprehensive project with real oral verification
- No committee-based entrustment model
- No clear mapping from artifacts to student outcomes

## What to remember
- Accreditation demands observable outcomes.
- Exemplar courses already use oral verification and project spine patterns.
- The course needs a defensible mapping from artifacts to outcomes.
- Dispositions must be visible, not implied.

## Why it matters for the course
This memo is the reason the redesign has to include assessment architecture, not just content architecture.

## Limits
It is a synthesis of external expectations, so the formal primary sources still matter for any public-facing claim.
