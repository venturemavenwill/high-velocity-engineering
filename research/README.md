# Research Workspace

Use this folder to collect the materials needed to turn the current Microsoft FTE/HVE notes into a university-grade AI systems / FDE course.

## Folder Map

- `00-inbox/` — temporary drop zone for raw downloads, copied notes, and unclassified material
- `01-course-structure/` — course spine, module order, prerequisites, and standards mapping
- `02-technical-foundations/` — AI systems theory, retrieval, inference, model training, and architecture foundations
- `03-measurement-evaluation/` — benchmarks, rubrics, validation methods, statistics, and evaluation artifacts
- `04-professional-formation/` — judgment, calibration, teamwork, resilience, and learning-science evidence
- `05-fde-craft/` — forward-deployed engineering practice, discovery, stakeholder work, and engagement cases
- `06-microsoft-platform/` — Microsoft product mapping, platform gaps, and version-specific references
- `07-accreditation-exemplars/` — ABET, CS2023, university syllabi, and academic comparators
- `08-assessment-epas/` — EPA definitions, entrustment evidence, oral-defense prompts, and rubric drafts
- `99-source-register/` — source log, citation index, and verification notes
Each strand folder should contain two files:

- `reading-list.md` — the curated bibliography for that strand
- `collected-materials.md` — the source-backed notes, summaries, and public-source excerpts we can safely retain in the repo

Copyright note: for books and paywalled papers, keep bibliographic entries and Cliff Notes-style summaries rather than copying full text. For open web sources, store the extracted notes, links, and synthesized takeaways in the folder.

## Suggested Use

Keep raw source material in `00-inbox/` first, then move or summarize it into the strand folder it belongs to. Use `99-source-register/` to track what was verified, where it came from, and whether it is durable or likely to age out quickly.
